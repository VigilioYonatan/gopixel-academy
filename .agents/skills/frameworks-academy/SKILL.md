# Frameworks Academy
Separar lecciones reales de simulaciones HTTP didácticas. Nunca afirmar que Gin corre en GitHub Pages. Para ejercicios con servidor nativo distribuir proyecto Go descargable, sin llaves, con tests reproducibles. Contenido en 6 idiomas cuando esté publicado. Cada framework: objetivos, prerequisitos, rutas, middleware, validación, tests, fallos y comparación de trade-offs.
