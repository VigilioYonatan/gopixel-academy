# Fondos y referencias visuales

- `landscape-light.svg/png`: paisaje pixelado para Light Mode.
- `landscape-dark.svg/png`: paisaje pixelado para Dark Mode.
- `landscape-senior.svg/png`: paisaje con acentos violeta para Senior Mode.
- `design-board.png`, `screen-concepts.png` y `approved-reference.png`: **concept boards visuales**, no capturas de una aplicación terminada. Algunas etiquetas dentro de esas imágenes pueden describir funciones futuras, como un compilador Go, y no prueban que estén desarrolladas.

Solo incorporar los SVG/PNG de paisaje y sprites a la interfaz real; no usar imágenes de maquetas como botones funcionales.
