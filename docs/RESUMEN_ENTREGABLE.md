### Orden recomendado

1. Ejecutar y revisar demo.
2. `npm install` y `npm run build` en equipo con acceso al registro npm.
3. Refinar y extraer features por dueño.
4. Implementar contenido básico verificable, y decidir runtime real.
5. Extender al currículo completo y Senior Mode por módulos.
