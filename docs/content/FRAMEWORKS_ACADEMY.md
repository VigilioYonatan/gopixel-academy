# Frameworks Academy — 8 rutas especializadas

Todas estas rutas se muestran en el catálogo; la implementación didáctica completa está planificada. El sitio estático no ejecuta servidores Go reales.

## F01 · net/http

**Subtemas:** ServeMux, handlers, HTTP request/response, httptest, middleware, errores.

**Ejercicios ligeros:** ordenar pasos, completar fragmentos, identificar middleware, quiz de API y explorar respuesta HTTP **simulada y etiquetada**.

**Laboratorio real:** proyecto `.go` con instrucciones y tests para descargar y ejecutar en máquina local.
