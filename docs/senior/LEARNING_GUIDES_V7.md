# Senior Guides v7 — Design and learning contract

The site provides 18 distinct technical reading guides under `/#/senior/S01/guide` through `/#/senior/S18/guide`.

Each includes five non-generic sections: context, invariants, test evidence, failure mode and ADR. The embedded Go source and tests are **byte-identical** to the 18 native labs. References are read-only for exploration; the online site does NOT execute them. Use the downloadable labs for `go test` and `go test -race`.

The guides are fully authored in Spanish. Navigation is localized to six languages; an explicit Spanish fallback warning is shown for non-Spanish users. Translations of all technical lesson prose remain a delivery blocker for full multilingual completion.

These guides satisfy study-material depth beyond multiple-choice content but do **not** certify professional senior experience.

> Rutas: `/#/senior/S01/guide` ... `/#/senior/S18/guide`. Son rutas dentro de la SPA; `senior-v7-demo-offline.html` funciona sin Vite para revisar el contenido.
