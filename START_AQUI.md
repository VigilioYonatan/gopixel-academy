# Iniciar GoPixel Academy v6

1. Vista previa offline: abre `senior-v6-demo-offline.html`.
2. Laboratorios reales: entra a `labs-native/`, instala Go 1.23+ y ejecuta `go test ./...` y `go test -race ./...`.
3. Para ejecutar la SPA Preact, resuelve npm desde un equipo con red: `npm install`, `npm run dev`; antes del deploy generar el `package-lock.json` y aprobar build/CI.
4. Senior Mode: `/#/senior`, `/#/senior/native`, `/#/senior/readiness` y `/#/senior/S05/native`.
5. Lee `AUDIT_REPORT_SENIOR_V6.md` para conocer el estado **parcial**.

**No hay Go WASM dentro del navegador ni cursos completos traducidos todavía.**
